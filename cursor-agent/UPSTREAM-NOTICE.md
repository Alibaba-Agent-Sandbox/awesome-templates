# Original Cursor Agent distribution

This template's authored Python, configuration and documentation use the repository
Apache-2.0 license. The downloaded Cursor Agent CLI belongs to Anysphere and is
subject to its [vendor terms](https://cursor.com/terms-of-service); no Apache license
or vendor endorsement is asserted for that software.

The build downloads the unchanged official versioned archive. Its original launcher,
bundled Node, native modules and all third-party notice files listed in `upstream.json`
are preserved byte-for-byte. No original Cursor source or binary is committed here.
The exact archive digest is controller-measured, not an upstream-published checksum.

Authenticated model/coding operation requires a genuine vendor credential. A local
argument fixture, native version/help or invalid-key refusal is not that acceptance.
