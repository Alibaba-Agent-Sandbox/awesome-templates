# Codex CLI usage

The maintained usage contract is in the template’s [English README](../codex/README.md) and [中文 README](../codex/README.zh-CN.md).

The maintained contract includes the pinned CLI, configuration, tool permissions, typed arguments, cancellation limits and artifact-based coding acceptance. A marker-only response is not coding acceptance.

Model settings must reach the server before it starts. Follow [runtime environment configuration](runtime-environment.md) ([中文](runtime-environment.zh-CN.md)) for prewarmed services. Use the same configured port from SDK, CLI and HTTP.
