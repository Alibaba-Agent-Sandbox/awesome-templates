# crush

## Purpose

Run official native Crush0.98.1 with private per-turn compatible-provider configuration on owned projects.

## Capabilities

CPU/non-root CLI, version/setup/structured run plus standard SDK files/shell. Default no tools; explicit eight coding tools. Subagent/MCP/jobs/network-fetch/LSP disabled. Interactive UI and arbitrary saved profiles excluded.

## Exposed API

See the complete [parameter table](../../crush/README.md#command-reference). Actual run --quiet --model owned/ID --small-model owned/ID --cwd DIRECTORY --data-dir PRIVATE with literal stdin. Both streams256KiB and wall1..1800seconds; no invented native max-turn flag. Read-only setup/version.

## Risks

Private HOME/XDG/native config/data with local foreground mode; refuse caller project Crush configs rather than execute them. Explicit model key/base in0600 config, filtered child env, no inherited cloud/GitHub/server keys. Permission mode is not an extra filesystem security boundary. Per-call identity-pinned process cleanup; sandbox deletion remains final boundary. FSL-1.1-MIT is not currently MIT or OSI-approved; preserve exact upstream terms.
