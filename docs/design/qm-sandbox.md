# qm-sandbox

## Purpose

Provide an actual Agent Sandbox Node.js SDK backend implementing the original QM Sandbox interface for one already owned Express computer. Original QM tool context performs real SDK-backed file and execution operations; no model account is required. Original full multiplayer core/web/Slack/Postgres durability/cron/subscription features are not started or qualified. Original default Docker backend is not used. This is a bounded original-library integration, not a shell program named qm or a replacement agent.

## Capabilities

Actual original QM createToolContext and original Node SDK for one existing owned project. Keyless SDK backend/execution/files; no model required. Outer cloud creation/deletion remains the caller's Python Sandbox SDK. No delegated sessions, external delivery, background jobs, other provider or durable multiplayer claim.
