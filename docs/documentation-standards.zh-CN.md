# 文档规范

适用于用户指南、模板 README、设计、贡献说明和新增工程记录。
[English](documentation-standards.md)。[模板规范](template-spec.zh-CN.md)定义精确 README/设计标题。

## 受众、位置与权威

先说明用户任务和可观察结果。通用用法放 `docs/`，模板参数放对应 README，设计理由放
`docs/design/`，实际验证放 `.agents/` 或模板 evidence。链接权威来源，避免复制会漂移的
契约。当前操作、历史研究和历史测试明确区分。可用性与可行性观察标日期，附来源或实测。

## 语言与结构

所有模板都有 README.md 和 README.zh-CN.md，严格遵循规范标题及顺序。通用规范和 step
指南具有互相链接的双语版本；行为、参数、设置、限制和验收措辞同一 PR 同步。规范指定
英文权威时以英文为准。两种语言中的代码标识、provider ID、命令、单位、错误码一致。

每页一个 H1，标题明确，段落简短，并列契约使用表格，代码块标语言。解释所有占位符，
区分必要、可选和默认值，注明单位及范围。避免本机绝对路径、未文档化别名和兄弟仓库
依赖；跨仓库使用完整 GitHub URL。

## 可运行示例与 API

每个模板用 CLI、Python SDK 和 HTTP POST 展示同一个有用任务。包含安装来源、提供方
配置、deploy/create、命令发现、参数、预期响应及自有资源清理。命令以真实帮助和源码为准。
示例明确实测还是仅语法检查，不能把示例当云端通过。

客户端包名为 agent-sandbox-client，按固定 SDK 版本选择导入；镜像安装 server 包。
未发布的包提供固定源码安装方法。区分有类型 JSON 和 CLI 字符串参数。HTTP 示例包含
方法、路由、headers、直接参数对象、result envelope、错误和认证。

命令参考写出每个参数的类型、必选/默认值、限制、输出 schema 和副作用。解释缓冲/流式、
执行截止时间与 HTTP 客户端超时、取消行为和进程所有权。说明配置优先级和启动时捕获的
设置，链接[预热服务指南](runtime-environment.zh-CN.md)。create env 不证明旧进程已重配置。

## 声明、限制与安全

事实必须有源码、上游一手文档或实测支撑。区分完整产品和切片。capability、安装成功、
模型 marker、mock 和绿色配置检查不能证明产品可用。Verified/tested_on 只列当前匹配
证据的提供方；保留历史失败和旧记录。

只使用占位 secret，不包含凭据、私有端点、资源 ID、签名 URL、私有 prompt 或原始敏感
日志。通过环境注入，不在命令参数写真实值。影响用户操作时写清权限、路径、资源成本和
清理；不得臆造端点或认证 header。

## 链接、维护与评审

相对链接从本文档目录解析，检查文件和 fragment，避免空链接和已删除目标。示例内的
占位链接明确标注。新增或修改的外部链接需验证，优先官方文档和不可变源码链接；网络
错误和受限页面独立记录。

运行 `python scripts/check_docs.py` 检查本地 Markdown 目标。修改 Python 示例时检查
语法；修改 README/schema 时运行严格模板检查。文档检查不触发云端测试。翻译、响应
示例、链接和日期一起评审。新增通用指南更新导航和贡献入口；纯文档也需要工程记录。
