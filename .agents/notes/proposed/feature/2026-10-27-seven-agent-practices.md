# Decision: Review seven native coding-agent experiences independently

Status: proposed

## Problem
Goose, Pi, DeepAgents, Kimi Code, Grok Build, Cline and Prime Agent needed real
configuration, native source edits, complete documented alternatives, actual
artifacts and their own practical articles before qualification.

## Decision
Preserve individual actual core/documented receipts and method inventory, including
Pi's fourth tools-check method and Prime's fourth kernel-check method. Require
fresh outputs and actual startup model changes. Retain all earlier failed attempts
and distinguish checker errors from an actual nonzero native process result.

## API Design
No runtime, manifest, schema or public method change. Evidence binds published
standalone/client/server, exact staged manifest/source/provider inputs and native
controller identities. Application credentials and model credentials stay separate.

## Alternatives considered
Model-only turns, version output, file reuse across consumers, synthesized account
errors or one generic article would not establish each requested experience.

## Dependencies
Refs https://github.com/Alibaba-Agent-Sandbox/awesome-templates/issues/244 and
https://github.com/Alibaba-Agent-Sandbox/blogs/issues/16. Registry receipts and
seven specific articles must land through their own owner repositories.

## Test Strategy
For each, actual default Docker/Express, native source repair, original three tests
unchanged, independently rerun original/held-out assertions and retrieved reports.
Then literal CLI/unchanged complete SDK/HTTP tasks with a second startup model,
fresh independently downloaded executable artifacts/reports, and owned cleanup.
Audit every declared named method; keep scope separate from optional upstream APIs.

## Acceptance criteria
All seven scoped method/task/configuration/consumer receipts are reviewed and
current-head checks pass; individual articles and Registry promotion follow.
The overall50-template request remains incomplete, including missing vendor/native
credentials and the managed interpreter defect. Do not close broad Issues.
