# Decision: Review nine additional practical template experiences

Status: proposed

## Problem
Four coding/session templates and five native utility templates required full public
method use, real business artifacts, documented consumers and individual articles.
Codex Agent API additionally had uncovered saved-agent GET and artifact DELETE routes.

## Decision
Retain per-template exact core/documentation identities and full method audit. Add
actual positive saved-config/artifact lifecycle and active-session deletion evidence.
Independently parse/decode/download utility artifacts and compile real programs.
Retain failed operator API assumptions with their actual cleanup results.

## API Design
No runtime or contract changes. Enumerate all named methods and15 actual custom
session/configuration/artifact routes, with independent post-deletion observation.
No extra cancel endpoint is invented. Credentials remain separate and unpublished.

## Alternatives considered
Version output, a model response, image push, a template create or reuse of old
output files cannot establish the requested observable business results.

## Dependencies
Refs https://github.com/Alibaba-Agent-Sandbox/awesome-templates/issues/244 and
https://github.com/Alibaba-Agent-Sandbox/blogs/issues/16. Individual articles and
Registry promotion belong to their own repositories. Native/Codex correction is
already merged at https://github.com/Alibaba-Agent-Sandbox/awesome-templates/pull/259.

## Test Strategy
Exact published tools/default recipes/Express; real source changes and independent
assertions for agents, literal CLI/full SDK/HTTP fresh tasks, artifact parse/execute,
all methods, two configured agent models, wrong-token and independent owned cleanup.
Record full OpenSandbox Goose/Aider/apply-patch use separately from Express.

## Acceptance criteria
Scoped receipts and current-head checks pass, followed by nine practical articles
and independently reviewed Registry promotion. Remaining full50-template work and
unavailable native account credentials prevent claiming the entire request done.
