# Decision: Add the actual pinned Kimi Code runtime

Status: proposed

## Problem

Issue48 requests the current Moonshot Node CLI. The older Python package or a
text-completion imitation would not implement that product. Reproducible install,
noninteractive configuration, permission semantics and real coding need verification.

## Decision

Install official npm @moonshot-ai/kimi-code2.2.0 on checksum-pinned Node24.16.0.
Keep actual upstream --prompt/stream-json behavior, private per-turn configuration,
explicit model endpoint/credentials, bounded output/deadlines and owned process
cleanup. Upstream prompt mode forces automatic tools and rejects --auto/--yolo;
require explicit allow_tools=True before invoking it rather than claiming read-only
behavior. Setup/version are separate keyless inspection commands.

## API Design

kimi_version(), kimi_setup_check(), and kimi(prompt, cwd="", command_timeout=600,
allow_tools=False). The model command returns buffered stream-JSON text or a
sanitized error. False permission refuses prompt-mode execution. The three
KIMI_MODEL_NAME/API_KEY/BASE_URL settings are required and provider type is explicit.
No session-resume API is promised. No cloud/registry key is passed to the CLI.

## Alternatives considered

The old Python runtime is the wrong upstream product. Passing --auto as a prompt
flag was rejected by the real2.2.0 executable and is removed. Inferring completion
from response markers would miss incorrect code; use actual files, unchanged tests
and post-response random acknowledgments in isolated Python.

## Dependencies

Issue: https://github.com/Alibaba-Agent-Sandbox/awesome-templates/issues/48.
Preparation dependency: https://github.com/Alibaba-Agent-Sandbox/awesome-templates/pull/121.
The official npm runtime/help/provider environment code was directly inspected;
upstream MIT notices remain in the package. Template wrapper remains Apache-2.0.

## Test Strategy

Actual process exit/timeout/descendant/output/secret/argv checks, local HTTP L0,
actual image pins and real Express deployment/calls/cleanup, then strict actual
compatible-model source edits, report and exact artifact, original tests and held-out
calculations. Keep failed attempts separate. Current-head CI and normal merge remain required.

## Acceptance criteria

- Complete standalone template, bilingual schema/docs/design and catalog entry.
- Exact installed Node/Kimi/server pins and non-root writable workspace.
- Local tests and relevant current-head CI pass.
- Real canonical Express L2 and image-backed model acceptance with independent cleanup.
- Scoped PR actually merged; Issue48 closes only after all its criteria hold.
