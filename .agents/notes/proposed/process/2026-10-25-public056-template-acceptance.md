# Record current published template acceptance

Status: proposed

## Problem

Current package instructions coexist with older source-candidate acceptance. Completed tests of public CLI 0.5.6 and Python client/server 0.4.0a6 need durable, accurate records without hiding the blocked default Express source journey or the two frozen native failures. The optional OSS guide also omits its existing local SDK prerequisite.

## Decision

Keep one dated summary and 100 byte-identical original receipts, indexed by local path and SHA256. Link the existing PR233 next-app proof in place. Update the README, bilingual usage and native-step guides, and engineering index. Document the existing OSS controller requirements only for the optional OSS route. Preserve historical evidence and every original failure.

## API Design

No runtime, API, manifest, recipe, dependency pin, version, support state or provider qualification table changes. Default source launch, managed entries, frozen native preparation and focused controls remain distinct evidence scopes.

## Alternatives considered

Refreshing 92 template READMEs would obscure the exact tested inputs. Duplicating old failure sets or the same raw proof across records adds no evidence. Counting native or OSS success as a default Docker pass, or relabeling a failed attempt after a fix, would misrepresent execution.

## Dependencies

Refs https://github.com/Alibaba-Agent-Sandbox/awesome-templates/issues/221 and https://github.com/Alibaba-Agent-Sandbox/awesome-templates/issues/223. This documentation branch integrates actual PR233 main `01279335dd4ecd8b252413344c67a42e59935e4f`. Test identities remain fixed separately at `4229` for default paths, `a936` for the native batch, and the exact focused control commits in the evidence. Default Express Docker reruns still need the missing operator prerequisites; Actions credentials have not been authorized for upload.

## Test Strategy

Verify original bytes and hashes, source and package identity, counts, and independent cleanup. Check bilingual links, the managed catalog, configured credential values and diff hygiene. Run normal latest-head CI after review. This documentation task requires no new cloud run or dependency installation.

## Acceptance criteria

Current links reach the dated summary, original receipts and focused-proof links. The 100 default cells retain 49 PASS / 46 BLOCKED / 5 NOT_APPLICABLE; the frozen native batch retains 44 PASS / 2 FAIL. Required current-head CI and review precede normal merge. Issues 221 and 223 remain open while their broader default-path acceptance is blocked. This records PR requires no new package version.
