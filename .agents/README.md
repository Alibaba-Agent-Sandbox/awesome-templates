# Template engineering records

Records own template/catalog decisions and actual checks. New records use English.
Use seven sections:Problem,Decision,API Design,Alternatives considered,Dependencies,
Test Strategy,Acceptance criteria. Notes live under notes/proposed or implemented
with architecture/feature/process categories; Status matches the directory.
Dated evidence lives under evidence/verify. Preserve merged evidence; new runs
receive new files. Separate PASS/PARTIAL/BLOCKED/FAIL; never store credentials.
Cross-repository references use absolute GitHub URLs.
