# Template engineering records

This repository owns template/catalog decisions and actual checks. New records use English.
Use seven sections: Problem, Decision, API Design, Alternatives considered, Dependencies,
Test Strategy, Acceptance criteria. Pending notes live under notes/proposed with an
architecture/feature/process category; accepted notes move to notes/implemented and update Status.
Dated evidence lives under evidence/verify. Preserve merged evidence and add new dated files.
Separate PASS/PARTIAL/BLOCKED/FAIL and keep credentials out. Cross-repository links are absolute.
